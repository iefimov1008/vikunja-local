# Vikunja Local

Проект установки и интеграции личного таск-трекера Vikunja на Mac mini.

## План

- Развернуть Vikunja с локальным хранением данных на Mac mini.
- Настроить защищённый доступ с Mac mini и MacBook.
- Подключить создание и управление задачами через веб-интерфейс и внешний чат.
- Добавить создание задач из явно принятых предложений по встречам.

## Статус

Репозиторий подготовлен для разработки. Установка и интеграция будут описаны по мере реализации.

Секреты, базы данных, вложения и расшифровки встреч в репозиторий не добавляются.
